# すごくじゃまなふせん (Sugoku Jamana Fusen)

> **「未処理を視界に貼りつけて逃がさない、すごくじゃまな付箋。」**

一般的なToDoアプリやメモアプリは、**「見ない」**という選択ができてしまいます。  
このChrome拡張機能は逆に、**「見ない自由を奪う」**ことを目的に作られた、視覚的圧力型タスクリマインダーです。

どのWebページを開いても、最前面に蛍光カラーの付箋が居座り続けます。  
「あと1本記事を書く」「このタスクのレビューを忘れない」など、絶対に忘れたくない未処理タスクを常に目の前に突きつけます。

---

## ⚡️ 特徴

- 📌 **全ページに常駐居座り**  
  ブラウザでどんなページ（`http://` / `https://`）を開いても、画面最前面に付箋が表示されます。スクロールしても逃げません。
- 🎯 **自由なドラッグ移動**  
  邪魔すぎる時は好きな位置へドラッグして移動可能。移動した位置は自動保存され、他タブや次回起動時にも引き継がれます。
- ✍️ **ページ上で直接編集**  
  付箋をクリックしてその場でメモを書き換え可能。もちろんツールバーの拡張アイコン（ポップアップ）からも一覧管理・作成・編集ができます。
- 🎨 **目立つ蛍光カラー & サイズ調整**  
  - **カラー**: 蛍光イエロー（デフォルト）、蛍光ピンク、蛍光グリーン、オレンジ、水色、白
  - **サイズ**: 小（1行メモ）、中（標準）、大（超重要タスク）
  - **透明度**: 40%〜100%（背景のみ透過し、文字の可読性をキープ）
- 🙈 **一時非表示スイッチ**  
  画面共有やオンラインミーティング時など、一時的に隠したい時はポップアップからワンクリックで全付箋をON/OFF切り替え可能（データは保持されます）。
- 🔄 **リアルタイムタブ同期**  
  開いているすべてのタブへ変更が即座に反映されます。ページのリロードは不要です。

## 📦 インストール方法（デベロッパーモード）

本拡張機能は、Chromeのデベロッパーモードから直接読み込んで使用できます。

1. **リポジトリをクローンまたはダウンロード**
   ```bash
   git clone https://github.com/yo4e/sugoku-jamana-fusen.git
   ```
2. **Chromeの拡張機能管理画面を開く**
   - アドレスバーに `chrome://extensions/` と入力してアクセスします。
3. **デベロッパーモードを有効化**
   - 右上の「**デベロッパーモード**」スイッチをONにします。
4. **拡張機能を読み込む**
   - 左上の「**パッケージ化されていない拡張機能を読み込む**」をクリックします。
   - クローン（または解凍）した `sugoku-jamana-fusen` フォルダを選択します。
5. **完了！**
   - ツールバーに「すごくじゃまなふせん」が追加されます。ピン留めしておくと便利です。

## 🛠 使い方

### 1. 付箋を作る
- 拡張機能アイコンをクリックしてポップアップを開きます。
- テキストを入力し、「**付箋を貼る**」をクリックします。
- 開いているWebページ上にすぐさま付箋が出現します。

### 2. 付箋を動かす・編集する
- **ドラッグ移動**: 付箋のヘッダーバーをドラッグして画面上の好きな場所へ動かせます。
- **直接編集**: 付箋の本文エリアをクリックして直接編集できます（自動保存）。
- **完了・削除**: 付箋の右上の「×」ボタンを押すと削除（完了）されます。

### 3. 見た目をカスタマイズする
- ポップアップから、付箋ごとに以下の設定が可能です：
  - カラーの変更（蛍光カラー含む6色）
  - サイズ変更（小 / 中 / 大）
  - 背景の透明度スライダー（40%〜100%）

### 4. 一時的に非表示にする
- ポップアップ上部のトグルスイッチで「表示中 / 一時停止中」を切り替えられます。

## 📂 ファイル構成

```text
├── manifest.json       # Manifest V3 拡張機能定義
├── background.js       # バックグラウンド・サービスワーカー
├── content.js          # Webページ側での付箋描画・ドラッグ制御
├── shared.js           # 定数・ストレージ管理・バリデーション共通処理
├── popup.html          # 管理用ポップアップUI
├── popup.js            # ポップアップのインタラクション・イベント処理
├── styles.css          # 付箋およびポップアップのスタイルシート
├── DESIGN.md           # 詳細設計書・思想仕様書
└── README.md           # プロジェクト概要
```

## 🛡 技術スタック & 権限

- **仕様**: Manifest V3
- **言語・設計**: Vanilla JavaScript (ES6+), Vanilla CSS（外部ライブラリ依存ゼロ）
- **利用権限**:
  - `storage`: 付箋データおよび表示設定のローカル保存
  - `tabs`: 開いているタブへのリアルタイム反映メッセージ送信
  - `scripting`: 拡張機能更新・読込時のアクティブタブ接続制御
  - `host_permissions`: `http://*/*`, `https://*/*`（Webページへの付箋重畳表示のため）
